SVG Elements Explorer

Discovering vector graphics through nature's patterns

SVG (Scalable Vector Graphics) is a language that describes two-dimensional graphics using XML. Unlike raster images that use pixels, SVG defines shapes mathematically, allowing them to scale perfectly at any size – much like how patterns in nature maintain their integrity across different scales.

The Circle Element

In nature, the circle appears in countless forms: the ripples on a pond, the full moon against the night sky, the eye of a bird. In SVG, the <circle> element captures this perfect geometry with mathematical precision. 

<svg width="200" height="200">
  <circle
    cx="100"
    cy="100"
    r="80"
    fill="#4CAF50"
    stroke="#2E7D32"
    stroke-width="3"
    opacity="0.8"
  />
</svg>

Adjust Properties:

Radius (r): 80
Center X (cx): 100
Center Y (cy): 100
Opacity: 0.8
Stroke Width: 3

Key Properties:

  • cx, cy: Center coordinates of the circle
  • r: Radius of the circle
  • fill: The color inside the circle
  • stroke: The color of the circle's outline
  • stroke-width: The thickness of the outline
  • opacity: The transparency level (0-1)

The Path Element

Just as rivers carve their course through landscapes, winding and flowing with organic precision, the <path> element allows us to create fluid, complex shapes that can represent anything from a leaf's delicate edge to a mountain's rugged silhouette. 

<svg width="200" height="200">
  <path
    d="M20,100 Q60,20 100,100 T180,100"
    fill="none"
    stroke="#228B22"
    stroke-width="4"
    stroke-linecap="round"
  />
</svg>

Adjust Properties:

Control Point 1 Y: 20
Control Point 2 Y: 100
Stroke Width: 4

Key Properties:

  • d: A sequence of commands defining the path
  • M: Move to a point (x,y)
  • Q: Quadratic Bézier curve to a point, with control point
  • T: Smooth quadratic Bézier curve to a point
  • stroke-linecap: Style of the ends of a stroke

Path Commands:

In the path's "d" attribute, letters represent commands and numbers represent coordinates. Uppercase letters (M) use absolute coordinates, while lowercase (m) use relative coordinates.

Key Properties:

  • x1, y1: Starting point of the gradient (percentages)
  • x2, y2: Ending point of the gradient (percentages)
  • <stop>: Defines colors along the gradient
  • offset: Position of the color stop (0-100%)
  • stop-color: Color at this position

Important Note:

SVG also supports radial gradients for circular transitions from a center point outward, mimicking how light disperses from a source in nature.

Continue your exploration of SVG elements as you would explore a forest - with patience, curiosity, and attention to detail.
